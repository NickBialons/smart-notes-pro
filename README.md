# 📝 Smart Notes Pro

> Дипломный проект — интеллектуальное веб-приложение для управления заметками с AI-анализом и облачным хранением.

---

## 🚀 О проекте

**Smart Notes Pro** — это современное веб-приложение для создания, хранения и анализа заметок. Приложение использует искусственный интеллект для автоматического извлечения ключевых слов, генерации тегов и краткого резюме текста. Данные синхронизируются в облаке через Firebase Firestore, что обеспечивает доступ с любого устройства.

---

## ✨ Функциональность

- 🔐 **Авторизация** — регистрация и вход через Firebase Auth (email + пароль)
- 👤 **Гостевой режим** — работа без аккаунта с сохранением в localStorage
- ☁️ **Облачное хранение** — синхронизация заметок через Firebase Firestore
- ✨ **AI-анализ** — автоматическое резюме, ключевые слова и теги через OpenRouter API
- 📊 **Живая статистика** — подсчёт слов, символов, предложений и абзацев в реальном времени
- 🔍 **Поиск и фильтрация** — поиск по тексту, сортировка и фильтр по приоритету
- 📤 **Экспорт** — выгрузка заметок в формате TXT
- 🗑️ **Управление заметками** — создание, редактирование и удаление с подтверждением

## ⚙️ Запуск проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/NickBialons/smart-notes-pro.git
cd smart-notes-pro
```

### 2. Установить зависимости

```bash
npm install
```

### 3. Задать переменную окружения (для AI-анализа)

```bash
# Windows
set OPENROUTER_API_KEY=your_api_key_here

# Linux / macOS
export OPENROUTER_API_KEY=your_api_key_here
```

### 4. Запустить сервер

```bash
npm start
```

### 5. Открыть в браузере

```
http://localhost:3000
```

> Без ключа OpenRouter AI-анализ будет недоступен, но все остальные функции работают в полном объёме.
